## Implementation

- `src/web-viewer/src/host/` detects Tauri with a small eager stub and loads
  the implementation with `import()`. Browser methods return no launch files
  or events. Native methods use the Tauri command/event API and plugin-fs
  `readFile`.
- Rust queues startup and second-instance paths until JS acknowledges each
  delivery. A pending read does not remove paths; the viewer acknowledges by
  launch ID only after its recipient callback completes. The adapter checks
  the queue periodically to recover a missed notification or failed pending
  read, and retries a failed acknowledgement without reopening the document.
  Rust logs notification failure while retaining the queue. It resolves
  relative paths against each launch's cwd,
  canonicalizes existing files, grants each file individually to the fs
  plugin's runtime scope, and focuses the existing window. The capability
  includes `fs:allow-read-file` with no static directory scope. No dialog
  plugin is registered.
- `receive()` retains `{sourceKind: 'host', path, name}` and passes a named
  `File` into the existing package/loose-document path. Path-based recents
  remain W3b work.
- NSIS config associates `.mdpkg`; the hook registers `.md` as an Open with
  candidate only. The known `.mdpkg` installer command quoting and uninstall
  orphan defects remain W4b work.

## Launch queue recovery limit and second review repair

The pending launch queue lives in the Tauri process. A process crash loses any
unacknowledged paths in that queue. This is an accepted W2 limit: launch paths
arrive in argv, and the OS supplies them again when the user relaunches the
file. W2 does not add a persistent queue. A cancelled unsaved-work prompt keeps
the path in the running process and reoffers it on the next host launch event;
a superseded open is retried by polling. A file that cannot be accessed or
granted file scope is queued with an error for the viewer to display, then
acknowledged as a deliberate rejection. A malformed file is likewise reported
and acknowledged after decoding fails.
